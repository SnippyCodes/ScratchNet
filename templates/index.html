How Users Can Run & Integrate Your Model

Your model is trained, validated, and ready for production. Here are the 4 ways users and developers can consume it:

🌐

1. Interactive Web App (Current)

Run this local web application. Anyone on your local network or Wi-Fi can open it in their browser and drag-and-drop photos.

# Start the web server py app.py # Or run with host 0.0.0.0 to share on local Wi-Fi

2. REST API for Web & Mobile Apps

Developers can send HTTP POST requests with any image to your FastAPI endpoint to get instant JSON predictions.

curl -X POST "http://localhost:8000/api/predict" \ -F "file=@my_flower.jpg"

Import your trained model into any Python script, data science notebook, or batch processing pipeline.

From NumPy MLP to PyTorch CNN: The Engineering Story

The project originated as ScratchNet, an MLP written in pure NumPy. While the MLP achieved 90% training accuracy, it flattened images into 67,500 1D vectors, losing all spatial geometry and dropping to 40% on real-world photos due to background color memorization.

Switching to this PyTorch Convolutional Neural Network solved the issue: 3 hierarchical convolutional blocks extract invariant edge and petal textures, while MaxPooling downsamples spatial dimensions (150 → 75 → 37 → 18). The model achieved a robust ~79% test accuracy across 2,240 test images on the 7 flower classes.
